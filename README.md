# 📌 Overview

**Stratum** is a full-stack AI-powered dermatology assistant designed to analyze skin-lesion images and classify them into **7 disease categories**.

The system combines:

* 🧠 **ConvNeXt** for skin-lesion classification
* 🔍 **OpenAI CLIP** for skin-image pre-filtering
* ⚡ **FastAPI** for backend API services
* 🔐 Secure authentication
* 📊 Interactive frontend
* 👨‍💼 Admin dashboard
* 📈 Model performance monitoring
* 🔄 Model versioning
* 🧑‍💻 Human-in-the-loop feedback
* ♻️ Verified-feedback-based model improvement

The goal of Stratum is not simply to build an image classifier, but to demonstrate how a computer-vision model can be integrated into a complete AI application with validation, authentication, monitoring, feedback, and continuous improvement.

# 🧠 AI Model

## ConvNeXt

Stratum uses **ConvNeXt** as its primary computer-vision architecture for skin-lesion classification.

ConvNeXt is a modern convolutional neural network architecture designed for strong visual-recognition performance while retaining the advantages of convolution-based models.

### Model Pipeline

```text
Input Image
     ↓
Preprocessing
     ↓
ConvNeXt Backbone
     ↓
Feature Extraction
     ↓
Classification Head
     ↓
7 Disease Classes
```

The trained model predicts the probability distribution across the seven supported classes and returns the highest-scoring classification.

---

# 🔍 OpenAI CLIP Skin-Image Pre-Filter

Stratum uses **OpenAI CLIP** as a pre-classification image-relevance filter.

CLIP is a vision-language model capable of comparing images against natural-language descriptions.

In Stratum, CLIP is used to determine whether an uploaded image resembles a relevant:

* Skin image
* Skin lesion

or an unrelated:

* Object
* Animal
* Food
* Document
* Building
* Scenery
* Other non-skin content

### CLIP Pipeline

```text
                    Uploaded Image
                           │
                           ▼
                    ┌────────────┐
                    │    CLIP    │
                    │ Pre-Filter │
                    └─────┬──────┘
                          │
                 ┌────────┴────────┐
                 │                 │
              Skin-like         Non-Skin
                 │                 │
                 ▼                 ▼
             ConvNeXt          Reject /
             Classifier         Warning
                 │
                 ▼
          Disease Prediction
```

### Important

CLIP is **not the disease-classification model**.

Its purpose is to provide an additional image-relevance check before the ConvNeXt classifier processes the image.

# 🔄 Human-in-the-Loop Learning

Stratum implements a **human-in-the-loop feedback system** to support continuous model improvement.

Users can provide corrections when they believe a prediction is incorrect.

### Feedback Pipeline

```text
Prediction
    ↓
User Review
    ↓
User Correction
    ↓
Verification
    ↓
Approved Feedback
    ↓
Training Data Update
    ↓
Fine-Tuning
    ↓
New Model Version
    ↓
Evaluation
    ↓
Deployment
```

Only **verified corrections** should be incorporated into future training cycles.

This prevents unverified user input from being automatically treated as ground truth.

# 🛡️ Limitations

Stratum has several important limitations.

### Dataset Bias

Model performance depends on the characteristics and distribution of the training data.

### Domain Shift

Performance may differ when the model receives images from devices, environments, or populations that differ from the training data.

### Image Quality

Blurred, poorly illuminated, occluded, or low-resolution images can negatively affect predictions.

### Skin-Tone Representation

Performance may vary across skin tones depending on the representation available in the training data.

### Visually Similar Conditions

Some dermatological conditions have similar visual characteristics and can be difficult to distinguish using images alone.

### CLIP Limitations

CLIP is used as a pre-filter and is not a clinical diagnostic system. It can also make incorrect image-text associations and should not be treated as a medical validation mechanism.

### Clinical Validation

The reported benchmark performance does **not** establish clinical effectiveness.

The current system requires additional external validation before it could be considered for real-world clinical use.
